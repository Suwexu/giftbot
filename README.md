# CyberX GiftBot

Telegram-бот для выдачи призов гостям клуба + визуальная админ-панель (Telegram Mini App).
Баланса больше нет: каждый выигранный приз попадает в личную «корзинку» гостя и лежит там
под замком 24 часа, после чего администратор выдаёт его на ресепшене через панель.

## Что внутри

- `bot.py` — точка входа: одновременно поднимает aiohttp-сервер (API + статика мини-аппов)
  и Telegram-бота (polling).
- `database.py` — SQLite: пользователи, призы, корзинка (`vault`).
- `security.py` — проверка `initData` Mini App (что запрос реально пришёл из Telegram).
- `webapp/static/guest/` — мини-апп для гостя: вкладки «Призы» и «Корзинка» с замком.
- `webapp/static/admin/` — визуальная админ-панель: дашборд, управление призами, корзинки гостей.

## 1. Настройка бота

1. У [@BotFather](https://t.me/BotFather) создайте бота (или используйте существующего),
   получите `BOT_TOKEN`.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Скопируйте `.env.example` → `.env` и заполните:
   ```
   BOT_TOKEN=...
   ADMIN_IDS=ваш_id
   PUBLIC_URL=https://<ваш-домен-на-railway>
   ```
4. У BotFather включите Mini App для бота: `/newapp` (можно указать любой short name),
   либо просто убедитесь, что у бота включён режим Web App (это не обязательно для
   инлайн-кнопок `web_app`, они работают у любого бота).

## 2. Деплой на Railway

Railway уже настроен (`railway.json`, `nixpacks.toml`). Просто:
1. Push в GitHub-репозиторий.
2. В Railway → Variables добавьте `BOT_TOKEN`, `ADMIN_IDS`, `PUBLIC_URL` (реальный домен,
   который Railway выдаст вашему сервису — его видно в Settings → Networking).
3. Deploy. После запуска откройте `https://<домен>/health` — должно быть `OK`.

**Важно:** `PUBLIC_URL` должен быть настоящим HTTPS-доменом — Telegram Mini App не откроется
по http или по localhost.

## 3. Как пускать в админку без команд

Админ просто открывает бота в личке → `/start` → под сообщением сразу две кнопки:
кнопка Mini App для гостевой части и кнопка «⚙️ Админ-панель». Панель проверяет
`initData` и Telegram ID: если id не в `ADMIN_IDS` — покажет экран `ACCESS_DENIED`,
даже если кто-то узнает ссылку.

## 4. Кнопка Mini App в группе (не команда)

У Telegram есть три механизма, у них разная область действия — учитывайте это:

**Вариант A (рекомендуется для групп): закреплённое сообщение с inline-кнопкой**
Кнопка типа `web_app` на сообщении бота работает в любом чате, включая группы.
Отправьте в группу сообщение с такой кнопкой и закрепите его — гости будут видеть
кнопку «🎁 Открыть CyberX» всегда сверху чата, без единой команды.
Технически это `keyboards.guest_app_inline_button()` в коде — можно повесить на
любое сообщение, которое бот отправит в группу (например, через отдельный
хендлер на добавление бота в группу, или отправить один раз вручную от админа).

**Вариант B: глобальная Menu Button бота**
`/setmenubutton` в BotFather → задать текст и URL Mini App. Это кнопка рядом с полем
ввода. Официально она относится к **личным чатам с ботом**, в группах Telegram её не
показывает — так что для вашего кейса (кнопка именно в группе) не подходит как
основной способ, но полезна как основная точка входа в личке.

**Вариант C: Attachment Menu (значок скрепки)**
`/setattach` в BotFather добавляет бота в меню вложений — тогда Mini App можно
открыть из любого чата, включая группы, через иконку скрепки. Требует, чтобы
пользователь один раз подключил бота в меню вложений.

Для вашей задачи — **вариант A**: закреплённое сообщение с `web_app`-кнопкой в группе.
Это даёт видимую постоянную кнопку, а не команду.

## 5. Логика призов и корзинки

- Гость нажимает капсулу в мини-аппе → `POST /api/spin` → сервер взвешенно (по полю
  `weight` приза) выбирает приз и кладёт запись в `vault` со статусом `locked`
  и `unlock_at = now + 24ч`.
- Статус `locked → unlocked` считается на лету по времени, ничего руками не разлочивается.
- Когда статус стал `unlocked`, администратор в панели (вкладка «Корзинки») жмёт
  «Выдать» → статус меняется на `issued`, дальше приз недоступен для повторной выдачи.
- Баланса как отдельной сущности в системе нет — только история призов в `vault`.

## 6. Управление призами визуально

Вкладка «Призы» в админке: список карточек с кнопками ✏️ (редактировать) и ✕ (удалить),
кнопка «+ Добавить приз» открывает форму (название, описание, картинка, шанс/вес,
остаток на складе, вкл/выкл) — всё мышью/тапами, без единой команды в чат.
